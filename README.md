# 終極課室座位表（Ultra Seat）

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-線上可用-brightgreen)](https://donaldcpk.github.io/ultra-seat/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Version](https://img.shields.io/badge/Version-v2.8.0-orange.svg)](CHANGELOG.md)

> **立即使用（免安裝）**：[https://donaldcpk.github.io/ultra-seat/](https://donaldcpk.github.io/ultra-seat/)

香港中學**班主任**用的排位＋課室管理網頁：誰不能坐一齊、擋壞桌、前排／SEN、列印學校正式 A4 座位表。開啟瀏覽器即可；學生資料只留在你的電腦。

## 為什麼需要這個？

CloudSAMS（前 WebSAMS）已有「編修座位表」、上傳相片、依班點名，但那主要是**畫座位圖**，不是日常課室管理。很多老師仍用 Word／Excel 做座位表。

本工具對標的是「座位表即課室管理面」的用法（類似海外 Class Charts／Seating Plan 的思路，但**只服務港校班主任、繁體中文、零安裝**）：

- 指定兩人不可同坐（四周／左右／前後）
- 擋壞桌、通道
- 前排／SEN 優先
- 每週換位：再次智能分配會盡量換離上次座位
- 一鍵匯出學校正式「班/科座位表(室)」A4 橫向 PDF，黑板在最下方，代課老師也看得懂
- 課室布局模板存本機，不用每次重擋桌
- 匯出分析 CSV（左鄰／右鄰）方便用 Excel 檢視

**不是**考務／試場編排工具。梅花座等考務選項若存在，只放在「更多」，不是產品主軸。

## 已實作功能

- **CSV 匯入**：新名單用 `班別,班號/學號,姓名[,職務][,前排/SEN]`，匯入後自動排位。若是本工具匯出的「座位分析」表，則按座位行／列還原原位、阻擋與空位，不會重新打亂
- **分析 CSV 匯出**：每格含狀態（已分配／空位／阻擋）、是否前排標記、左鄰、右鄰；空位與阻擋一併列出，方便對應課室。正式表請用 A4 列印，不要用 CSV 代替
- **課室格網**：2×2 至 **12×12**（一般中學課室足夠）
- **阻擋座位**：壞桌、柱、通道
- **不可同坐**：兩位學生四周／左右／前後不可相鄰
- **智能分配＋週更**：回溯法 + MRV；有上次方案時優先換位，並顯示換了多少人；過密會清楚失敗（有搜尋上限，不宣稱 100%）
- **分配檢查報告**：每組不可同坐標示已遵守／失敗；前排／SEN 未進前兩排會列出
- **前排／SEN**：CSV 填「是」時優先試前兩排（**不會**從姓名猜性別）
- **課室形狀**：只記行列、室、壞桌（本機模板，不含學生）
- **記住這一班**：名單與座位存在這部電腦，重新打開可載回，不上傳
- **A4 橫向 PDF**：`班/科座位表(室)`、每一格都畫出來、格內三行（姓名、學號、職位）、右下教師桌、左方「班主任：姓名」、最下方黑板；PDF 程式放在專案內，學校網路擋外網仍可下載

## 刻意不做

| 項目 | 說明 |
|------|------|
| 依姓名推斷性別 | 不做（港校不宜） |
| 班幹部自動前排、性別均衡、最小間距 | 舊文件曾寫、**未實作**；已不宣傳 |
| 試場／禮堂／考務為主產品 | 不做為主軸 |
| 英文介面／多語系／帳號雲端 | 本階段不做 |
| 遙測 | 不做；名單不上傳 |

## 快速開始（班主任）

1. 打開[線上版](https://donaldcpk.github.io/ultra-seat/)或本機雙擊 `index.html`。頁首是三步：匯入、調位、匯出。不用先按建立課室
2. 左邊填班別、室、班主任，匯入 CSV。新名單會自動排位；座位分析表會回到原位。班名或室改了，標題立刻更新
3. 點一個座位，再點另一格對調。壞桌用「擋壞桌」開關
4. 右邊按「匯出橫向 PDF」
5. 「記住這一班」把名單和座位留在這部電腦；下次按「載入上次」
6. 隨機分配、範例、統計、梅花座、校名、日期、課室形狀都在「更多」

## CSV 欄位

建議標題列（UTF-8）：

```text
班別,班號,姓名,職務,前排
中三甲,01,陳志明,班長,
中三甲,04,黃嘉欣,,是
中三甲,05,張偉強,,
```

| 欄位 | 必填 | 說明 |
|------|------|------|
| 姓名 | 是 | |
| 班號 或 學號 | 是 | |
| 班別 | 建議 | 顯示與進階「同組分散」用 |
| 職務 | 否 | |
| 前排 或 SEN | 否 | 填 `是`／`1`／`SEN` |

仍支援舊檔：`學號,姓名,職務`。

## 如何匯出橫向 PDF

1. 畫面上已有姓名分配（中間已是正式表格預覽）
2. 按「匯出橫向 PDF」→ 會下載 A4 橫向檔
3. 若下載失敗，可用「列印（備用）」並選 **A4 橫向 → 另存 PDF**
4. 應見：`班/科座位表(室)` 標題、格內姓名＋學號＋職位、右下教師桌、左方班主任、**最下方黑板橫條**

## 私隱

- 純前端；名單與座位只在瀏覽器
- 課室形狀只含格網、室與阻擋，**不含**學生名單
- 「記住這一班」含名單與座位，仍只在這部電腦
- 公用電腦用完請關閉分頁

## 安裝與開發

```bash
git clone https://github.com/Donaldcpk/ultra-seat.git
cd ultra-seat
# 瀏覽器開啟 index.html，或：
python3 -m http.server 8080
```

```bash
node test_school_edition.js
```

## 架構

```text
index.html              # 單一網頁（介面、CSV、解算、列印、課室形狀）
vendor/                 # 橫向 PDF 用的程式（不必連外網）
test_school_edition.js  # 核心邏輯單測
CHANGELOG.md            # 版本變更
```

解算器針對**一班約 36–40 人、少量不可同坐**；達節點或時間上限則回報失敗。
